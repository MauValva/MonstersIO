# Placeholders de arte

Substitua os assets desta pasta pelos sprites finais do jogo. A primeira versão usa formas desenhadas diretamente com Pixi.js para permitir testar a mecânica antes da integração da arte.

Sugestão de organização:

- `player/` — estados e evoluções do monstrinho
- `eggs/` — ovos e efeitos de coleta
- `world/` — tiles, obstáculos e base
- `ui/` — ícones, joystick e elementos do HUD
